================================================
시세 — 에스크로(안전거래) 완전 쉬운 설명
================================================


■ 한 줄로 에스크로가 뭐냐
------------------------------------------------
"돈을 판매자에게 바로 안 주고, 시세가 잠깐 보관했다가
 물건이 무사히 도착한 걸 확인한 뒤에 판매자에게 넘겨주는 것."

→ 사기 원천 차단. 판매자가 잠수타도 구매자 돈은 안전.


■ 왜 필요한데?
------------------------------------------------
중고 거래 안 하는 이유 1위 = "사기 당할까봐"
- 돈 보내면 물건 안 옴
- 물건 사진이랑 다름
- 판매자 잠수

에스크로가 이걸 다 막아준다.
크림/번개장터가 이거 때문에 뜬 것.


■ 어떻게 굴러가냐 (4단계)
------------------------------------------------
[1단계] 구매자가 결제
   → 카드/계좌이체로 돈 낸다
   → 이 돈은 판매자한테 안 감

[2단계] 시세가 대금 보관 (에스크로)
   → 시세 명의 계좌에 대기
   → 판매자에겐 "결제 완료됐으니 물건 보내세요" 알림만

[3단계] 배송 → 구매자 수령 확인
   → 물건 받고 상태 체크
   → "확인 완료" 버튼 누름
   → (안 누르면 7일 뒤 자동 확정)

[4단계] 판매자에게 정산
   → 이 순간 시세가 판매자 계좌로 이체
   → 문제 있으면 즉시 환불 (돈은 시세 손에 계속 있었으니 가능)


■ 실제로 만들려면 내가(사용자가) 뭘 해야 되냐
------------------------------------------------
결론: 직접 만들 필요 없다. 결제회사(PG)가 다 만들어놨다.
      우린 API만 붙이면 끝.

[할 일 순서]

1) 사업자 등록
   - 통신판매업 신고 (개인도 가능)
   - 정부24 사이트에서 3만원 정도
   - 소요 시간: 몇 분

2) 결제회사 선택 & 가입 신청
   추천 3사:
   - 토스페이먼츠 (요즘 스타트업 표준, 심사 빠름) ← 추천
   - 포트원 (구 아임포트, 개발자 편함)
   - KG이니시스 (전통 강자)
   준비물: 사업자등록증, 사이트 URL, 통장 사본
   심사 기간: 2~5일

3) 에스크로 옵션 체크
   - PG사 대시보드에서 "에스크로 사용" 체크
   - 별도로 은행이랑 계약 안 해도 됨
   - PG사가 이미 에스크로 라이선스 가지고 있음

4) 개발자가 API 연동
   - 결제 요청할 때 escrow: true 파라미터 추가
   - 코드 한 줄 수준
   - 개발자 2~3일이면 끝

5) 정산 규칙 정하기
   - "수령 확정 후 며칠 뒤 정산?" (보통 즉시 or 1~3일)
   - "자동 확정은 몇 일?" (보통 7일)
   - "반품/환불 조건은?"


■ 이거 어려운 작업이냐? — 쉽게 말하면
------------------------------------------------
[기술 난이도]  ⭐⭐ (5점 만점)
  → 쉽다. 결제 붙여본 개발자면 3일이면 끝.
  → PG사가 문서/샘플코드 다 줌.

[운영 난이도]  ⭐⭐⭐⭐
  → 이게 진짜 어려움.
  → "물건이 사진이랑 다르다" 클레임 오면 누가 판정?
  → 환불 기준이 뭐냐?
  → 반품 배송비는 누가?
  → 이런 정책 문서화 + 고객 응대가 진짜 골치.

[한 줄 요약]
"기술은 쉽고, 정책이 어렵다."


■ 지금 (데모데이/지원서 단계) 뭐 해야 되냐?
------------------------------------------------
실제 결제 붙이지 마라. 시간 낭비.

지금 필요한 건:
✅ 에스크로가 뭔지 웹사이트에서 명확히 보여주기 (완료)
✅ 4단계 플로우 시각화 (완료)
✅ "안전거래 100% 보장" 카피 (완료)
❌ 실제 결제 API 연동 (❌ 나중에)

투자자/심사관이 "결제는 어떻게 할 거냐?" 물어보면
→ "토스페이먼츠 에스크로 API로 붙일 예정, 개발 3일"
→ 이 답변이 정답.

실제 결제는 초기 유저 100명 붙고 나서 붙여도 안 늦음.
그 전엔 데모 UI로 충분히 검증 가능.


■ 순서 정리 (내가 언제 뭐 하면 되냐)
------------------------------------------------
지금 ~ 데모데이:
  → 지금 이 웹사이트로 발표. 실제 결제 X.

데모데이 이후 ~ 초기 유저 모집:
  → 통신판매업 신고
  → 토스페이먼츠 가입 신청

초기 유저 50~100명 붙었을 때:
  → 개발자 시켜서 에스크로 API 연동 (3일)
  → 첫 실거래 시작

그 이후:
  → 분쟁 처리 정책 문서화
  → 고객 응대 팀 셋업
